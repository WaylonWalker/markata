# Edit feeds visually

Open the Go workbench for your site and choose **Feeds** from the workspace
sidebar. Feed Studio appears beside the existing workspace navigation.

Choose a feed, then edit its title, description, post filter, ordering,
presentation, or HTML template. The settings are stored in your site's
`markata-go.toml`, `markata-go.yaml`, `markata-go.yml` or
`markata-go.json`, not in a separate Feed Studio database.

## Write a filter

The **Post filter** field uses Markata's ordinary filter language, not a
different editor-only syntax. For example:

```text
published == true and 'python' in tags
```

The **Matching posts** view updates after you type. It displays the number
of matches or an inline syntax error. A syntax error disables **Save feed
settings**. Select **Edit post** on any result to open its real Markdown
source in the editor. Use **Back to feed** to return.

## Preview the site template

Choose **Built site** to display HTML generated by your most recent site
build. This retains the actual layout and theme, including a custom
`templates.html` value, rather than approximating a theme with generic
editor cards.

This preview is **not a live build**: after changing a filter or template,
the editor shows the live matching-posts result. Run your normal Markata
build to regenerate the actual page, then refresh Feed Studio to inspect
the new output.

If no build exists or the output directory is outside the local workspace,
the editor tells you that the built-site view is unavailable. Feed
configuration and membership editing still work.

## Save, review, publish

Choose **Save feed settings** to change the site's config file.
These changes can then be reviewed and published through the existing
workspace Changes and publishing workflow. Feed Studio protects against
concurrent edits: if another process has changed the config file, the
save is rejected and your current form values remain visible.

Feeds authored in an included configuration file can be inspected but are
currently read-only in Feed Studio. Edit their source configuration to
change them until source-aware includes are supported.

For the complete feed model see [Feeds](feeds.md) and
[Feed Views](feed-views.md).
