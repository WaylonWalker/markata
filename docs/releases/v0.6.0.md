Markata v0.6.0 focuses on two things every publishing workflow needs: pages that arrive quickly and private writing that stays private.

## A lighter path from build to browser

CSS bundling, minification, critical CSS, resource hints, and unused-style analysis give sites new ways to reduce delivery overhead. Glob caching and performance benchmarks help keep repeated builds responsive. View transitions and infinite-scroll pagination add smoother movement through feeds.

## Keep private content private

Encrypt post bodies at rest and decrypt them for authorized readers. The release also adds a built-in 404 page with slug suggestions, giving visitors a useful next step when they follow an outdated link.

## Get started

Download the [v0.6.0 release](https://github.com/WaylonWalker/markata/releases/tag/v0.6.0) or inspect the [source tag](https://github.com/WaylonWalker/markata/tree/v0.6.0). Review the current [encryption guidance](/docs/guides/encryption/) before enabling private content.
