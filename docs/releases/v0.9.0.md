Markata v0.9.0 removes friction from setup and daily site work. Tailwind CSS automation handles more of the wiring for you, while a clearer CLI makes commands and errors easier to understand.

## A more responsive workflow

Hot builds get faster, CSS purging runs in parallel, and benchmark diagnostics make performance easier to investigate. Slug modes support flat, path-based, and hybrid URLs. View transitions improve navigation, and video previews use smaller assets.

## Less setup, more control

Managed Tailwind configuration now fits into the normal workflow, with better handling of inline attributes. The release also improves starter templates, feed cards, and theme details.

Download the [v0.9.0 release](https://github.com/WaylonWalker/markata/releases/tag/v0.9.0) or review the [source tag](https://github.com/WaylonWalker/markata/tree/v0.9.0).
