Markata v0.3.0 helps readers find their way around and gives site owners a clearer path from local build to deployment.

## Better discovery and structure

Pagefind search now follows the active palette and improves readability. The layout system adds four presets, multi-feed sidebars, and path-based navigation, so a site can grow without every page needing a custom template. Keyboard shortcuts speed up common reader actions, while stronger contrast improves all 25 included palettes.

## A smoother route to production

New performance benchmarks and parallel file loading help identify and reduce build costs. Docker support and deployment guidance make self-hosting more approachable, Android ARM64 joins the build targets, and the migration tool helps Python Markata users move their content.

## Get started

Download a binary from the [v0.3.0 release](https://github.com/WaylonWalker/markata/releases/tag/v0.3.0) or inspect the [source tag](https://github.com/WaylonWalker/markata/tree/v0.3.0). See the [current deployment guides](/docs/guides/deployment/) for supported publishing workflows.
