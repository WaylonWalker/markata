Markata v0.14.0 is the first canonical release of the Go project under the `markata` name. It pairs that identity change with a more editorial reading experience and practical improvements for site owners.

## A new name, with a careful path forward

The Go module and repository now use `github.com/WaylonWalker/markata`, and `markata` is the preferred executable. The `markata-go` command remains available for existing workflows. This remains a 0.x project: existing `markata-go.toml`, `[markata-go]`, and `MARKATA_GO_*` configuration continue to work.

## Give archives a magazine feel

Weekly editorial feeds bring lead stories, photo essays, relative dates, and native Older/Newer navigation together. Offscreen content and optional controls can wait until needed, improving the initial reading experience. The image library gains opt-in pagination and keeps the site's palette and typography.

## Improve the work behind publication

`markata triage` creates a focused diagnostic handoff for people and agents. Builder Admin makes source and build provenance easier to inspect, and retained workspaces reduce repeat publication work. Reader, accessibility, and responsive theme details also receive careful refinements.

## Upgrade

Download the [v0.14.0 release](https://github.com/WaylonWalker/markata/releases/tag/v0.14.0) or install the Go command with:

```sh
go install github.com/WaylonWalker/markata/cmd/markata@v0.14.0
```

The `markata` PyPI package changed from the historical Python distribution to the Go CLI after this release. Older pinned versions remain the original Python implementation; see the [installation guide](/docs/installation/) before changing an existing environment.

For the full technical history, see the [v0.13.0 to v0.14.0 comparison](https://github.com/WaylonWalker/markata/compare/v0.13.0...v0.14.0) and [release rollout guide](/docs/guides/releasing/).
