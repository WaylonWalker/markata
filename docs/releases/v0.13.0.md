Markata v0.13.0 adds a personal place for the links worth keeping and improves the machinery that turns a source tree into a published site.

## Keep the web you want to remember

The built-in `/pins` board presents saved links with covers and notes. It gives a site a simple, native way to collect references, recommendations, and things to revisit.

## Publish with less repeated work

Build planning gains deterministic digests and clearer stage boundaries. Builder Admin can reuse retained workspaces and move release cleanup outside the promotion lock, reducing unnecessary work during incremental publication. Asset minification becomes incremental, while font-pack diagnostics explain configuration conflicts more clearly.

Download the [v0.13.0 release](https://github.com/WaylonWalker/markata/releases/tag/v0.13.0) or inspect the [source tag](https://github.com/WaylonWalker/markata/tree/v0.13.0). Check the [CLI reference](/docs/reference/cli/) for the current command surface.
