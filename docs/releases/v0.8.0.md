Markata v0.8.0 brings a faster development loop and a more accessible experience for readers. Warm builds benefit from plugin-level caching, while the `--fast` option skips expensive production steps during local iteration.

## Rich media without the usual weight

GitHub Gists render as highlighted code, and YouTube previews use a lightweight embed that delays the full player. Expanded oEmbed discovery improves the experience for other media providers too.

## Make themes more inclusive

New palette tools generate coordinated colors and enforce WCAG contrast requirements. The release also improves incremental serving and private-content encryption workflows.
