Markata v0.4.0 brings more of the site-building workflow into the tool itself. Clearer commands and reusable site components make routine publishing easier, while new content features add depth to the finished site.

## Build and manage with confidence

Create content from multiple templates, update configuration with `config set`, preview palettes, and run the self-update command. More useful errors point to the affected file and suggest a fix. Layout selection can follow site configuration, and automated theme checks help protect accessibility as designs change.

## Bring more of the web into your site

Internal and external embeds, an import command for bringing in outside content, breadcrumbs, content statistics, and a complete documentation layout broaden what a Markata site can do. The release also expands benchmarking and Python Markata migration support.
