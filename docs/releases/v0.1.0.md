Markata v0.1.0 is the first release of the Go static site generator: a complete starting point for publishing Markdown as a fast, customizable website.

## A complete publishing foundation

The initial release brings together Markdown processing, Jinja-style templates, a nine-stage plugin lifecycle, and more than 15 built-in plugins. Use filter expressions to shape content, then publish it as HTML, RSS, Atom, or JSON Feed. A theme and palette system gives sites a consistent look, while the live reload server keeps the writing loop short.

The release also establishes cross-platform binary distribution, so contributors can get started without building the tool themselves.

## Get started

Download a binary from the [v0.1.0 GitHub release](https://github.com/WaylonWalker/markata/releases/tag/v0.1.0), or browse the [source tag](https://github.com/WaylonWalker/markata/tree/v0.1.0). This is an early 0.x release; expect the project and its interfaces to continue evolving.
