Markata v0.7.0 makes local iteration faster and brings more of the linked web into your posts.

## Spend less time waiting on builds

The new `--fast` option for `build` and `serve` skips expensive production-only work during development. Plugin-level caching, parallel minification, and permanent timing instrumentation make warm builds quicker and help reveal where time goes.

## Give links a richer preview

Embeds add support for GitHub Gists, YouTube, TikTok, Giphy, and a broader set of oEmbed providers. Choose embed modes and classes or configure providers to fit a site's style. Hashtag references and richer garden connections add new ways to navigate related ideas.

The release also strengthens encryption behavior across rendered output, including private-tag feed cards.
