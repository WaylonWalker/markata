Markata v0.12.0 opens a lighter way to get started: render a standalone page without first assembling a complete site configuration. For established sites, better serving controls and stronger build diagnostics make iteration and operations more transparent.

## Start small, then make it yours

The serve interface gains a more useful settings sidebar and a redesigned theme picker. Theme and rendering improvements refine long-form reading, palette switching, navigation, and responsive layouts. Expressive headings and richer feed presentation help content feel at home in the site.

## Understand what the build is doing

Content diagnostics and image-library improvements expand the tools available to site owners. Release-directory and site-directory workflows make it easier to manage build inputs and outputs, while effective-configuration provenance clarifies which settings are active.

## Get started

Download the [v0.12.0 release](https://github.com/WaylonWalker/markata/releases/tag/v0.12.0) or view the [source tag](https://github.com/WaylonWalker/markata/tree/v0.12.0). Read the [configuration guide](/docs/guides/configuration/) before adapting an existing site.
