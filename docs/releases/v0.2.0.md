Markata v0.2.0 makes the first release easier to use every day. New-site commands, starter content, and an installation script shorten setup, while richer navigation and publishing options give writers more room to shape their sites.

## Write, organize, publish

Start a project with `init` or create content from the CLI. Use a Markdown index as the homepage, custom slugs, tag feeds, and multiple output formats to organize a site around the way you write. Internal links gain hover previews, and YouTube links can become embedded media.

Published pages also gain canonical URLs, social preview metadata, and structured data. Configurable layouts, pagination, IndieAuth, and Webmention settings connect the site to the wider web. The new `explain` command gives both people and coding agents useful project context.

## Get started

Download a binary or view the [v0.2.0 source](https://github.com/WaylonWalker/markata/tree/v0.2.0). For installation and first-site guidance, start with the [current installation guide](/docs/installation/).
