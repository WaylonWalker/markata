Markata releases grow a tool for turning Markdown into a site you own. This archive gives each version a clear theme, the changes that matter to writers and readers, and links to the original source and downloadable release.

## Recent releases

- [v0.15.0 — Markdown That Travels from Site to App](/docs/releases/v0-15-0/) — Python rendering, Go and browser workbenches, richer Markdown.
- [v0.14.0 — The Markata Name, A More Editorial Web](/docs/releases/v0-14-0/) — canonical Go identity, editorial feeds, more dependable publishing.
- [v0.13.0 — Pinboards and More Reliable Publishing](/docs/releases/v0-13-0/) — saved links, retained workspaces, incremental assets.
- [v0.12.0 — Single-File Sites, Better Serving, Theme Refresh](/docs/releases/v0-12-0/) — standalone pages, serve controls, clearer build provenance.
- [v0.11.0 — A Fresh Reading Experience and Better Site Insight](/docs/releases/v0-11-0/) — refreshed theme, image library, content diagnostics.
