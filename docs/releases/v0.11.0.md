Markata v0.11.0 gives sites a more considered reading experience and gives authors better tools for understanding their content.

## A theme made for long reads

The refreshed default theme improves typography, cards, sidebars, palettes, and accessibility. Readers can adjust text size, and expressive Markdown headings add more personality without custom templates.

## See and manage your content

Create a searchable image library with copyable image links and bundled fonts that work offline. A versioned Content Index and diagnostics ledger make publication decisions easier to inspect. Encryption and private-feed projections support safer workflows for sensitive writing.

The release also advances build performance and improves operational safeguards in the deployment chart.

## Get started

Download the [v0.11.0 release](https://github.com/WaylonWalker/markata/releases/tag/v0.11.0) or review the [source tag](https://github.com/WaylonWalker/markata/tree/v0.11.0). See [theme guidance](/docs/guides/themes/) and [frontmatter documentation](/docs/guides/frontmatter/) for ways to use these features.
