# Getting started

You do not need to learn the entire plugin system before publishing something.

**Your first hour:** install, create a directory, write one Markdown post, then build.

1. [Install Markata](/docs/installation/) — pick your operating system or installer.
2. [Run the quickstart](/docs/quickstart/) — `markata config init`, `markata new`, `markata serve`.
3. [Install the bundled agent skill](/docs/guides/agent-skills/) — let your agent work from accurate site-specific instructions.
4. [Follow the authoring guide](/docs/guides/authoring/) — posts, drafts, tags, links, and images.
5. [Deploy the output](/docs/guides/deployment/) — static hosting needs no Markata process in production.

Later, explore [themes](/docs/guides/themes/), [feeds](/docs/guides/feeds/), [templates](/docs/guides/templates/), and [plugins](/docs/reference/plugins/).

Markata is the **Go** project at [WaylonWalker/markata](https://github.com/WaylonWalker/markata). It is still **0.x**. The original Python product lives at [WaylonWalker/markata-py](https://github.com/WaylonWalker/markata-py), and current PyPI releases install the Go CLI after a version break. Older Python versions remain available when pinned; see [installation](/docs/installation/).
