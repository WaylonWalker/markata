01 / install

One command to start.

Pick an install method. Releases are single binaries, with no Python runtime needed.

curl

curl -fsSL https://raw.githubusercontent.com/WaylonWalker/markata/main/install.sh | bash
markata version

Linux / macOS · Read the installer source first.

Bash

curl -fsSLo install-markata.sh https://raw.githubusercontent.com/WaylonWalker/markata/main/install.sh
less install-markata.sh
bash install-markata.sh

Inspect, then execute the shell script.

mise

mise use -g github:WaylonWalker/markata

Manage releases with mise. Historical downloads may provide the `markata-go` name.

Go

go install github.com/WaylonWalker/markata/cmd/markata@main

Current source requires Go 1.27+. Use `@main` for the renamed entry point until a canonical tagged release.

GitHub

Download the correct archive for your platform, verify its checksum, and move the extracted binary into your PATH.

Browse GitHub Releases →

PyPI

python -m pip install markata

Python Markata, not Go. PyPI still hosts the original Python project. Use another tab to install this Go binary. Details →

The canonical Go executable is `markata`; `markata-go` remains a compatible alias. All installation details →

02 / hand it to an agent

Give the agent the manual.

Markata ships a skill for OpenCode, Codex, Claude Code, Cursor, and other harnesses. No copied prompt bundle required.

cd my-site
markata agent list-agents
markata agent install
markata agent doctor

Or target a harness: markata agent install --agent opencode

03 / make something

Write Markdown. Publish HTML.

No theme customization, feed plumbing, or plugins needed for your first post.

mkdir my-site && cd my-site
markata config init
markata new "Hello World"
markata serve

Preview at localhost:8000. When ready, markata build produces static files.
